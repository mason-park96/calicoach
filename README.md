- 홈 루틴 미리보기, 운동 중, 휴식 중에 `동작 배우기` 열기 가능
- 운동·휴식 중 동작 배우기 열면 일시정지(닫은 뒤 직접 재개)
- 검증된 ACE 운동 사진 페이지 및 NHS 시연 영상 페이지 링크 제공 (일부 종목). GIF만으로 정확한 자세를 배우지 않도록 구별 표시
- 기존 GIF·추천 알고리즘·로컬 프로필·기록 저장·JSON 백업 그대로 유지
- 업데이트 캐시 버전 `calicoach-shell-v1.4.0`

**실제 사람의 운동 시연 영상은 아직 앱에 직접 포함되어 있지 않습니다.** 외부 페이지 링크는 온라인 접속이 필요합니다. 출처 사진/영상은 복제하거나 재배포하지 않았습니다.

## 개인 정보, 운동 유의점

계정/백엔드 없음. 이름·신체정보·기록은 기기 `localStorage`에만 저장하며 다른 기기로 동기화하지 않습니다. 개인 기기의 홈 화면 앱과 Safari의 데이터 저장소가 다를 수 있습니다. 주기적으로 JSON 백업을 권장합니다.

이 앱의 추천 규칙은 운동 초보자의 건강 상태를 판단하는 의료용 알고리즘이 아닙니다. 날카로운 통증·증상 악화·방사통·새로운 감각 이상 발생 시 운동을 중단하고 의료 전문가와 상의하세요. 모든 운동이 모든 사람에게 적절하다는 보장은 없습니다.

자세 시연은 이해를 돕는 **스틱 피겨 형태의 움직임 개념 애니메이션**이며 전문가의 실제 시범 영상이 아닙니다. 실제 인체 시연 영상은 다음 버전의 콘텐츠 제작 과제입니다.

상세 설계와 근거: [`docs/09_training_engine_design_v1.3.md`](docs/09_training_engine_design_v1.3.md)
