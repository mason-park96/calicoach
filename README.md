# 칼리코치 Calisthenics Coach · PWA v1.1.0

3인용 개인 맨몸운동 PWA. 서버, 백엔드, PostgreSQL, 외부 라이브러리 없이 **GitHub Pages**에서 그대로 동작합니다.

## v1.1.0 추가된 기능

- **3명 사용자 선택/이름 입력:** 박무승(남성), 이수희(여성), 권승용(남성)
- **자동 로그인:** 체크하면 마지막 사용자를 이 기기의 LocalStorage에 기억합니다. 체크 해제 시 탭/브라우저 세션에만 기억합니다.
- **처음 로그인할 때 신체정보 입력:** 생년월일, 키, 체중, 목표 체중, 운동 경험, 정자세 푸시업 횟수(선택), 주당 운동 횟수, 운동 시간, 운동 목표, 허리·발바닥 유의사항
- **개인별 루틴:** 입문/보통/숙련에 따라 A/B 코스와 동작/반복 횟수를 조정합니다. 운동시간에 따라 2/3/4라운드를 제안하며 목표에 맞춰 기본 휴식 시간을 설정합니다. 성별은 강도 결정에 사용하지 않습니다.
- **개인별 데이터 분리:** 사용자별 신체정보·체중·운동 내역·진행 중인 운동·설정을 독립적으로 저장합니다.
- **내 신체정보 수정:** 설정 → 신체정보 수정
- **이전 v1.0 데이터 가져오기:** 박무승 계정에서 설정 → v1.0 기록 가져오기. 이 기기에 이전 저장 데이터가 존재할 때만 표시됩니다. 이전 원본은 보존합니다. 같은 기기라면 체중/목표 체중만 첫 입력 화면에 자동 채워질 수 있습니다.
- 기존 운동 UI, 타이머, 음성 안내, 운동 기록, JSON 백업/복원, 오프라인 기능은 유지했습니다.

## 중요: 데이터와 로그인 방식의 한계

**이름 선택은 진짜 인증이 아닙니다.** 비밀번호가 없어 누구나 저장된 사용자명으로 해당 기기의 데이터에 접근할 수 있습니다. 각 사용자의 기록이 소프트웨어적으로 분리되는 방식일 뿐입니다.

**각 아이폰 데이터는 서로 동기화되지 않습니다.** 예를 들어 박무승이 아이폰 A에서 기록한 운동 결과는 아이폰 B로 자동 전송되지 않습니다. 동일 아이폰에서 여러 사용자를 선택하면 사용자별 저장 공간을 분리합니다.

LocalStorage는 브라우저/PWA의 저장소입니다. 기기 변경, Safari 웹사이트 데이터 삭제, 앱 삭제, 일부 저장소 정책 등에 의해 사라질 수 있습니다. 설정의 JSON 백업을 주기적으로 사용하세요. 저장 공간을 비우지 않고 앱 파일만 GitHub Pages에 업데이트하는 경우에는 일반적으로 기록이 유지됩니다. 브라우저와 홈 화면 웹앱 간 저장소가 분리되는 환경도 있으니 같은 설치 앱에서 사용하세요.

### 개인정보 주의

GitHub 저장소가 Public이라면 **소스코드에 정의된 3명 이름과 성별은 공개**됩니다. 생년월일·키·체중·건강상 제약은 소스에 하드코딩하지 않고 이용자가 자신의 기기에서 입력하도록 했습니다. 최초 체중과 목표 체중은 같은 기기에 있던 v1.0 저장 데이터를 읽어 채워질 수 있습니다. 본인의 실제 측정값이나 운동 기록 백업 JSON은 GitHub에 커밋하지 마세요.

## 설치 / 버전 교체

1. ZIP을 압축 해제하고 파일을 확인합니다: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `icons/`.
2. 기존 GitHub 저장소를 clone했다면 해당 폴더의 파일을 교체합니다. **`.git` 폴더는 삭제하거나 덮어쓰지 않습니다.**
3. Git Bash에서:

```bash
git status
git add index.html app.js styles.css sw.js manifest.webmanifest README.md
# 아이콘을 변경하지 않았다면 별도 추가 필요 없음
git commit -m "feat: add three-user local login and profile-based workouts"
git push origin main
```

4. GitHub Pages 배포가 반영되면 아이폰 PWA를 완전히 닫았다가 다시 실행합니다. 오프라인 캐시는 `calicoach-shell-v1.1.0`으로 변경했습니다.
5. 최초 로그인 시 사용자를 선택하고 신체정보를 저장합니다.

GitHub Pages의 주소를 바꾸거나 다른 출처(origin)로 옮기면 LocalStorage도 달라지므로 백업이 필요합니다.

## 운동 개인화 규칙 (초기 버전)

- 경험 수준 **입문**: 무릎 푸시업, 스쿼트, 브리지, 데드버그 등 기본 동작 위주
- 경험 수준 **보통**: 일반 푸시업, 스쿼트, 리버스 런지, 스플릿 스쿼트, 플랭크 등
- 경험 수준 **숙련**: 템포 푸시업 등으로 일부 동작 난이도 상승
- 20분: 기본 2라운드 / 30분: 3라운드 / 45분: 4라운드 (설정에서 수동 변경 가능)
- 목표가 감량 중심이면 기본 휴식 20초, 균형이면 25초, 근력 중심이면 40초
- 정자세 푸시업 최대 횟수를 입력하면 일부 푸시업 동작의 초기 반복 횟수 상한에 반영
- 허리·발바닥 제약은 주로 입문 단계에서 무리한 동작 대신 대체 동작을 사용하는 데 참고합니다. 진단/의학적 처방은 아닙니다.

이 규칙은 **1차 규칙 기반 추천**이며 운동능력을 정밀 평가하는 개인 트레이너나 의료 프로그램이 아닙니다. 실제 수행 능력과 통증 반응을 기준으로 반복 횟수·강도를 조절하세요.

## 수동 테스트 체크리스트

- 최초 실행: 사용자 3명 표시 / 이름 직접 입력 / 존재하지 않는 이름 차단
- 자동 로그인 ON: 앱 재시작 시 홈 또는 입력 중 화면 복귀
- 신체정보 최초 입력: 필수 입력값 검증 / 키·체중 / 목표 / 수준 / 회수·시간 설정
- 로그인 후 설정 > 신체정보 수정 및 재접속 시 값 유지
- 박무승/이수희/권승용 전환 시 프로필·운동 기록이 섞이지 않는지 확인
- 입문 사용자: 무릎 푸시업과 기본 동작 확인
- 보통 사용자: 푸시업/스쿼트/런지 확인
- 시간 20/30/45 분: 기본 라운드 2/3/4
- 운동 A/B 자동 교대, 이전 단계/휴식/일시정지, 재실행 시 운동 이어하기
- 사용자별 JSON 백업 및 동일 계정 복원, 잘못된 계정 백업 차단
- 기존 v1.0 데이터 있는 동일 기기에서 박무승 사용자 기록 가져오기
- 아이폰 홈 화면 앱과 Safari에서 실제 반영 상태 확인

## 테스트 범위

v1.1.0 빌드 시 Node.js 문법 검사와 브라우저 API를 모의한 JavaScript 상태·로직 테스트를 통과했습니다. 이 실행 환경에서는 실제 브라우저 자동 실행이 차단되어 **iOS Safari 실기기 테스트는 아직 완료하지 못했습니다.**
