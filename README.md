# 칼리코치 Calisthenics Coach — PWA v1.0

**개인 맞춤형, 아이폰 홈 화면에 설치해 사용하는 30분 내외 칼리스데닉스 앱.**

Mac/Xcode/유료 Apple 개발자 계정/서버 프로그램/외부 라이브러리 없이 작동합니다. `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`만으로 이루어진 정적 웹 앱입니다.

## 기능

- 운동 시작 버튼 하나로 A/B 루틴 자동 교대
- 준비운동(4분) → 전신 근력 서킷(기본 3라운드) → 보강 → 정리(2분)
- 한 화면에 한 동작과 횟수, 짧은 자세 팁 제공
- 횟수 미세 조정 및 운동 자세 상세 설명
- 운동 완료 터치 → 휴식 카운트다운 → 자동으로 다음 동작 시작
- 1~4라운드 및 10~90초 휴식 시간 설정 (라운드 간 휴식 별도)
- 한국어 음성 안내 선택, 효과음 선택 (iOS 재생 제한 가능)
- 운동 완료 횟수/날짜/시간 기록 및 체중 변화 그래프
- 기록 JSON 파일 백업 및 가져오기
- 오프라인 캐시(service worker), 홈 화면 아이콘, 독립 실행형 UI

> 주의: 화면 잠금 또는 백그라운드 상태에서는 iOS 타이머 이벤트/음성 출력이 지연·중단될 수 있습니다. 다시 화면을 켜면 종료시각을 이용해 남은 시간을 재계산합니다. 아이폰의 진동 API는 지원되지 않을 수 있어 기능을 넣지 않았습니다.

## 1. Windows에서 로컬 테스트

압축 해제 후 `index.html`을 더블클릭해도 대부분 기능은 작동하지만 `file://`에서는 오프라인 Service Worker가 동작하지 않습니다.

Python이 설치된 경우 해당 폴더에서 PowerShell을 열고:

```powershell
py -m http.server 8080
```

PC 브라우저에서 `http://localhost:8080/`에 접속합니다. **아이폰에서 오프라인 PWA로 설치할 때는 HTTPS 웹 주소가 필요하므로 아래 배포를 진행하세요.**

## 2. GitHub Pages로 공개 배포하기 (Windows만으로 가능)

1. GitHub에서 새 저장소를 생성합니다. 예: `calicoach`. 무료 계정이라면 **Public** 저장소를 선택해야 Pages를 사용할 수 있습니다.
2. 압축을 풀고 **폴더 안의 파일들**(`index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `icons` 폴더)을 저장소 루트에 업로드합니다. `CalisthenicsCoach_PWA_v1.0/` 폴더 자체를 업로드해 하위 폴더에 `index.html`이 들어가지 않도록 주의하세요.
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save** 를 설정합니다.
4. 배포 후 GitHub Pages가 알려주는 `https://<GitHub사용자이름>.github.io/<저장소이름>/` 주소를 아이폰에서 엽니다. (이 URL은 형식 예시이며 실제 주소는 GitHub 화면에서 확인하세요.)
5. iPhone Safari → 메뉴(공유) → **홈 화면에 추가** → **웹 앱으로 열기(Open as Web App)** 켜기 → **추가**.
6. 홈 화면의 **칼리코치** 아이콘을 눌러 실행합니다. 앱 파일을 한 번 온라인에서 캐시한 후에는 인터넷이 없어도 기본 기능을 이용할 수 있습니다.

> GitHub Pages 사이트와 소스는 외부에서 열람 가능합니다. 운동 기록은 **각 기기의 로컬 저장 공간**에만 저장되므로 GitHub 저장소로 올라가지 않습니다. JSON 백업 파일을 저장소에 업로드하지 마세요.

### Git CLI로 배포 (선택)

```bash
git init
git add .
git commit -m "Initial Calicoach PWA"
git branch -M main
git remote add origin https://github.com/<GitHub사용자이름>/<저장소이름>.git
git push -u origin main
```

위 명령 실행 전에 GitHub 저장소를 생성하고 원격 주소의 자리표시자를 실제 값으로 교체하세요.

## 3. 운동 커스터마이즈

- A 루틴: 일반 푸시업, 스쿼트, 리버스 런지, W 레이즈, 데드버그
- B 루틴: 스플릿 스쿼트, 템포 푸시업, 한발 글루트 브리지, T 레이즈, 사이드 플랭크 양쪽
- 보강운동: A는 글루트 브리지+플랭크, B는 데드버그+플랭크
- 본운동 기본 3라운드(1~4라운드 변경 가능)
- 단계별 기본 횟수는 `app.js`의 `exercise` 데이터에 있고, 운동 화면 ±로 횟수를 조정하면 기기에 저장됩니다.
- A/B 교대는 완료된 운동만 기준으로 합니다. 중간에 종료하면 해당 루틴을 다시 추천합니다.

## 4. 데이터 저장 및 백업

- `localStorage` 키: `calicoach.pwa.v1`
- 최초 사용자 예시 체중 92kg, 목표 80kg; 기록 화면에서 수정 가능
- **설정 → 운동 기록 JSON 백업** 으로 파일을 정기적으로 저장할 것을 권장합니다. iPhone에서 공유 시트가 열리면 **파일에 저장**을 선택하세요.
- 동일한 웹앱을 다른 주소로 옮기거나 브라우저 저장 공간을 지우면 데이터가 자동으로 이동하지 않습니다.
- 홈 화면 앱과 Safari의 사이트 데이터 저장 공간은 실행 방식/iOS 버전에 따라 분리되어 보일 수 있습니다. 운동 기록은 홈 화면 앱 내부에서 관리하고 백업하세요.
- 백업 가져오기는 기존 데이터를 교체합니다.

## 5. 제한사항

- 앱은 공개 호스팅이 필요하지만 개인 데이터를 업로드하거나 계정을 만들지 않습니다.
- 사진/동영상 자세 시연, Apple 건강 앱 연동, 서버 백업, 푸시 알림은 현재 포함하지 않습니다.
- 운동 중 화면을 켜두어야 음성/타이머 안내가 안정적이며, 홈 화면 PWA에서 화면 잠금 방지 기능은 브라우저 지원 여부에 따라 달라집니다.
- 허리·발바닥 증상이 증가하는 동작은 중단·조정하세요. 허리디스크를 포함한 개인 진단에 대한 의료 처방 앱은 아닙니다.
- 실제 운동 시간은 운동 속도 및 라운드 설정에 따라 달라지므로 정확히 30분에 종료된다고 보장하지 않습니다.
