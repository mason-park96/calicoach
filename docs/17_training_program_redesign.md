# Calicoach 운동 프로그램 재설계안

> 이후 사용자 요청에 따라 현재 앱은 초급·중급·고급을 직접 선택하는 간편 방식으로 변경했다. 이 문서의 자동 승급·최초 4회 적응 등은 이전 단계의 기록이다. 현재 동작은 [간편 수준 설정 명세](18_simple_levels_and_date_layout.md)를 따른다.

작성·근거 확인: 2026-10-28. 상태: **맨몸 기본형을 추천 엔진·진행·기록 화면에 반영. 밴드 로우 확장형은 시연 자료 확보 후 추가**.

구현: `coach-engine.js`, `app.js`, `styles.css`, `sw.js`. 기본 세트 배분·시간 예산·입문 적응·회복 선택·실제 수행/좌우/여유 기록·즉시 하향·상한 2회 성공·통증 범주 제외·걷기 기록·백업 v5를 적용했다. 기존 완료 기록과 체중은 보존하며 과거 진행도는 별도 보관한다. 실제 자세를 자동 판정하지 않으며 정밀한 운동 강도 측정이나 임상 효과 검증을 구현한 것은 아니다.

검증: `node tests/training-engine-test.js`의 13,824개 조합과 `tests/smoke-test.js`, `tests/guide-test.js` 통과. 브라우저에서 주간 일정·세트별 목표·실제 입력 3회 후 다음 세트 2회 하향을 확인했다. 적응기는 달력 주차를 강제하지 않고 입문자의 완료한 일반 세션 최초 4회를 기준으로 적용한다.

## 1. 목적과 적용 범위

집에서 짧게 운동하고, 시연을 보며 배우고, 기록을 통해 발전하는 기존 취지를 유지한다. 기본 권장안은 **주 3회 전신 저항운동 + 별도 걷기**, 시간 제약이 있으면 주 2회로 시작한다. 매번 새로운 운동을 제공하기보다 같은 동작의 수행 능력을 확인하고 조절한다.

기본 대상은 일반적인 운동을 수행할 수 있는 성인 입문자·중급자다. 이 문서는 특정 질환·부상에 대한 재활 처방이나 개인별 진단이 아니다. 고령자, 임신·산후, 통증이나 기능 제한이 있는 사용자는 별도 조정이 필요하며 나이·불편 부위 체크만으로 적합성을 판정하지 않는다.

목표는 기초 근력·근지구력과 지속적인 참여를 개선하는 것이다. 최대근력·근비대 극대화에는 맨몸 부하의 한계가 있으므로 장비 확장 경로를 제공한다. 현재 루틴보다 효과가 클 것이라는 설계상의 근거는 있지만, 이 앱의 개선 효과 자체를 임상시험으로 입증한 것은 아니다.

## 2. 근거를 적용하는 원칙

| 근거 | 설계에 반영할 내용 | 해석의 한계 |
|---|---|---|

| 밴드 저항운동 메타분석, 2019 [6] | 접근성을 유지하면서 당기기 부하를 추가할 선택지로 밴드 활용 | 8개 연구에서 비교 방법 간 유의한 우월성이 없었음. 모든 밴드 운동과 기구 운동의 동등성이 입증된 것은 아님 |
| CDC 활동 강도 안내 [7] | 걷기의 중강도 기준을 대화 가능·노래 어려움으로 설명 | 개인별 상대 강도의 간단한 판단 도구이며 정밀 측정이 아님 |

이하의 반복 범위, 2회 연속 성공, 주차별 도입 방식, 시간별 세트 배분은 위 원칙을 구현하는 **프로젝트 설계값**이다. 해당 숫자의 조합 전체가 논문에서 최적 프로그램으로 검증됐다는 의미가 아니다.

## 3. 기본형과 확장형

### 기본형: 맨몸과 매트 중심

현재 영상으로 스쿼트, 푸시업, 브리지, 견갑 보조운동, 코어를 구성한다. 의자나 높은 지지대는 실제 사용 가능 여부를 확인한 경우에만 선택한다.

W·T 레이즈와 리버스 스노우 엔젤은 `scapularAccessory`로 분리한다. 로우와 같은 `horizontalPull`로 집계하지 않는다. 따라서 기본형은 **실제 등 당기기 부하가 부족한 입문 코스**라고 표시한다. 브리지만으로 햄스트링의 모든 기능이나 후면 사슬의 모든 운동을 충족한다고 설명하지 않는다.

### 확장형: 밴드 당기기 추가

검수한 밴드 로우를 도입해 견갑 보조운동 자리에 배치한다. 사용 가능한 밴드·해당 방식의 지지/고정 조건과 시연 자료가 확보된 경우에만 활성화한다. 임의의 문틀·책상·가구에 체중이나 밴드를 걸도록 안내하지 않는다.

밴드 로우는 신규 운동 ID·가이드·사용 허가가 확인된 시연 영상이 필요하다. 현재 제공 중인 운동이나 기존 영상이 이미 있는 것처럼 표시하지 않는다. 이후 후면 사슬의 추가 부하, 종아리, 수직 당기기 등은 목표와 장비에 따라 확장할 수 있다. 이 5개 슬롯만으로 모든 근육의 훈련을 완벽히 충족한다는 표현은 사용하지 않는다.

## 4. 주간 일정

| 선택한 운동 가능 일수 | 저항운동 | 나머지 활동 |
|---|---|---|
| 주 2일 | 월 A / 목 B, 다음 주도 A/B | 가능한 날 걷기. A와 B 모두 주요 슬롯을 포함 |
| 주 3일 · 기본 권장 | 월 A / 수 B / 금 C | 걷기 및 휴식 |
| 주 4일 | 월 A / 수 B / 금 C | 토 걷기·가벼운 움직임을 정식 일정에 배치 |
| 주 5일 | 월 A / 수 B / 금 C | 화·토 걷기·가벼운 움직임을 정식 일정에 배치 |

근력운동 사이에 하루를 두는 일정을 기본값으로 한다. 이는 회복을 확보하기 위한 운영 규칙이며, 모든 사람에게 정확히 48시간이면 회복된다는 판정이 아니다. 회복이 덜 됐으면 추가로 쉬거나 강도를 낮춘다. 같은 근육군을 연속된 날에 강하게 훈련하지 않도록 한다. [8]

일정을 놓치면 다음 가능한 날에 다음 루틴을 수행한다. 몰아서 보충하거나 두 세션의 세트 수를 합치지 않는다. 걷기 권고량에는 운동 가능 일수에 등록하지 않은 날의 일상 활동도 포함할 수 있다.

## 5. 30분 기준 A/B/C 본운동

아래는 도입기를 마친 사용자의 기본 템플릿이다. 푸시업은 이름이 아니라 실제 반복 가능 범위에 맞춰 벽·높은 지지대·무릎·일반형 중 선택한다. A/B/C는 난도 등급이 아니다. C라고 자동으로 더 어려운 동작을 주지 않는다.

| 슬롯 | 월 A | 수 B | 금 C | 세트 / 목표 |
|---|---|---|---|---|
| 무릎 중심 하체 | 스쿼트 | 스플릿 스쿼트 또는 스쿼트 | 스쿼트 | 3 / 스쿼트 8~15회, 스플릿 좌우 6~10회씩 |
| 상체 밀기 | 개인 수준의 푸시업 | 같은 푸시업 | 같은 푸시업 | 3 / 6~12회 |
| 고관절 폄 | 글루트 브리지 | 글루트 브리지 | 글루트 브리지 | 2 / 10~20회 |
| 등 당기기 · 확장형 | 밴드 로우 | 밴드 로우 | 밴드 로우 | 2 / 8~15회 |
| 위 슬롯의 기본형 대안 | W 레이즈 | T 레이즈 | W 레이즈 또는 스노우 엔젤 | 2 / 8~15회, 견갑 보조로 별도 집계 |
| 코어 | 데드버그 | 사이드 플랭크 또는 데드버그 | 버드독 또는 플랭크 | 2 / 아래 설명 참조 |

등 당기기와 견갑 보조는 **동시에 필수로 하는 두 슬롯이 아니라 모드에 따른 한 슬롯**이다. 한 세션은 총 5개 슬롯, 12세트다.

- 스플릿 스쿼트는 균형과 자세를 유지할 수 있을 때만 도입한다. 처음에는 A/B/C 모두 스쿼트여도 된다. 스플릿이 안 된다는 이유만으로 무조건 런지나 브리지로 바꾸지 않는다.
- 브리지가 상한 반복에서 충분히 쉬워지면 같은 목적의 한발 브리지 좌우 8~15회로 재평가한다. 한발형이 너무 어려우면 양발형으로 돌아간다. 옆으로 다리 들기·클램셸을 고관절 폄의 상위 단계로 쓰지 않는다.
- 데드버그·버드독: 좌우 각각 6~10회, 몸통을 통제할 수 있는 범위. 실패 반복을 만들기보다 자세가 무너지기 전에 종료한다.
- 플랭크: 20~40초. 사이드 플랭크: 좌우 각각 15~30초, 좌우 전환 약 15초. 좌우를 합쳐 한 쌍의 세트로 집계하며 각 측 수행은 따로 기록한다.
- 레이즈·스노우 엔젤도 무조건 탈진시키지 않는다. 통제된 움직임과 편안한 범위를 우선하고, 쉬워졌다고 로우와 같은 부하 발전을 달성했다고 처리하지 않는다.

기존 시연과 가이드를 재사용하되 실제 움직임·명칭·반복 방식이 이 표와 일치하는지 검수한다. 모든 보유 동작을 루틴에 억지로 넣을 필요는 없다. 클램셸·다리 벌리기는 필요와 여유에 따라 별도 고관절 벌림 보조운동으로 제공한다.

## 6. 운동 순서와 휴식

기본 진행은 다음과 같다.

1. 준비운동 3~5분: 가볍게 걷거나 제자리 움직임 → 편안한 관절 움직임 → 선택한 스쿼트·푸시업의 쉬운 연습 세트. 연습 세트는 본운동 세트에서 제외한다.
2. 블록 1: 스쿼트 1세트 → 휴식 → 푸시업 1세트 → 휴식. 각 3세트가 되도록 반복한다.
3. 블록 2: 브리지 1세트 → 휴식 → 로우 또는 견갑 보조 1세트 → 휴식. 각 2세트 수행한다.
4. 블록 3: 코어 2세트. 좌우형은 양쪽을 수행한 뒤 다음 세트로 센다.
5. 마무리 1~3분: 편하게 움직이며 호흡을 가라앉힌다. 스트레칭은 원하는 경우 편안하게 시행한다.

본운동의 서로 다른 종목 사이 휴식은 **60초부터 시작**하고 60~90초 내에서 수행 상태에 맞춘다. 힘든 세트 뒤에는 더 길게 쉰다. 동일 종목을 연속 수행하는 모드에서는 필요에 따라 2~3분을 허용한다. 짧은 견갑 보조·코어는 45~60초로 충분한 경우 조절할 수 있다.

상·하체 교대에서 같은 종목이 다시 돌아올 때까지의 회복 시간은 중간 종목의 수행 시간과 두 휴식 구간을 포함한다. 따라서 종목 사이 타이머만 보고 같은 근육군의 휴식이 부족하다고 판정하지 않는다. 반대로 전신 호흡이 회복되지 않았는데 교대 운동이라는 이유로 진행을 강제하지 않는다.

동작 속도는 반동 없이 통제하는 것을 우선한다. 예시로 내리기 약 2초·올리기 약 1초를 안내할 수 있지만 모든 운동에 강제하지 않는다. 기존 3초 내리기·1초 올리기 템포 영상은 선택 변형으로 남긴다. 느린 동작이 언제나 더 효과적이라는 설명은 하지 않는다.

## 7. 20·30·45분의 배분

| 목표 시간 | 하체 / 밀기 / 고관절 폄 / 로우 또는 견갑 / 코어 | 기본 세트 합계 | 운영 |
|---|---|---|---|
| 20분 | 2 / 2 / 2 / 2 / 1 | 9 | 짧은 완주형. 좌우 운동이나 긴 휴식이면 보조 슬롯 세트를 줄이되 각 슬롯 최소 1세트 유지 |
| 30분 | 3 / 3 / 2 / 2 / 2 | 12 | 기본 권장형 |
| 45분 | 3 / 3 / 3 / 3 / 2 | 14 | 회복이 충분할 때 확대. 남는 시간은 걷기 또는 선택 보조운동 |

주 3회 30분형의 운동별 명목 세트는 하체 9, 밀기 9, 고관절 폄 6, 당기기 6, 코어 6이다. 기본형의 **부하를 건 실제 로우 세트는 0**이며 견갑 보조 6세트로 표시한다. 주 2회는 각각 6/6/4/4/4세트다. 좌우 각 1세트는 각 측에 1세트를 제공한 것이며, 전신 주간량을 2배로 부풀리지 않는다.

이는 운동별 집계다. 겹쳐 쓰는 모든 근육에 같은 수의 유효 세트가 배정됐다는 뜻은 아니다. ACSM이 제시한 근비대 목적의 주간 고용량 방향을 초보자가 반드시 채워야 할 최소량으로 취급하지 않는다. [1][2]

시간 추정은 `준비 + 각 세트 실제 예상 수행시간 + 전환 + 필요한 휴식 + 마무리`로 계산한다. 좌우 동작은 양쪽 시간을 합친다. 30분형에서 12세트×약 40초, 세트 사이 11구간×60초, 준비·마무리 6분, 전환 1분이면 약 26분이다. 느린 동작·좌우 동작·추가 휴식에 따라 30분을 넘을 수 있다.

시간 초과 시 먼저 선택 보조운동을 제외하고, 이후 세트를 줄인다. 목표 시간에 맞추려고 동작을 서두르거나 필요한 휴식을 강제로 줄이지 않는다. 5개 슬롯을 각 1세트까지 줄여도 시간이 부족하면 예상 소요 시간을 알리고 사용자가 연장 또는 종료하도록 한다. 45분 선택이 45분 내내 고강도 운동을 요구하는 것은 아니다.

## 8. 초기 난도 선택과 발전 규칙

### 초기 평가

실패까지 최대 반복을 시키기보다, 쉬운 변형으로 짧게 연습하고 목표 범위의 낮은 쪽을 수행한다. 끝에서 좋은 자세로 몇 번 더 할 수 있을지 묻는다. 푸시업 최대 횟수만으로 다른 부위의 수준을 결정하지 않는다.

- 도입기: 3~4회 정도 여유를 남길 수 있는 수준.
- 적응 후 본운동: 대체로 2~3회 여유(RIR 2~3)를 기본 안내로 사용.
- 코어·견갑 보조: 자세 통제가 종료 기준. 모든 종목을 실패 근접도만으로 평가하지 않음.

초보자의 RIR 추정은 부정확할 수 있으므로 `많이 남음 / 2~3회 정도 / 거의 없음 / 통증·이상`처럼 설명한다. 이를 센서로 확인한 정확한 측정값처럼 표시하지 않는다. RIR 2~3은 실용적 운영 목표이지 누구에게나 유일한 최적점은 아니다. [1][4]

### 반복 수와 난도의 조절

| 관찰 결과 | 다음 행동 |
|---|---|
| 목표 범위 내 완수, 적절한 여유·자세 유지 | 같은 변형 유지. 여유가 충분하면 다음 수행에서 세트당 1회 정도 증가 |
| 모든 세트가 상한 도달, 여유 2회 이상, 통증 없이 2회 연속 운동에서 성공 | 부하 또는 동작 변형 중 하나만 높이고 반복을 범위 하단으로 재설정 |
| 하한 반복도 어렵거나 자세 붕괴·여유 거의 없음 | 그 세트를 종료. 다음 세트의 목표를 줄이거나 쉬운 변형으로 하향 |
| 하향 후에도 반복해서 어려움, 다음 운동에도 회복 미흡 | 다음 세션에서 해당 종목 1세트 감량 또는 쉬운 날로 전환 |
| 통증·이상 증상 | 해당 동작 중단. 단순 ‘힘듦’과 분리해 기록하고 동일 부하 재시도를 자동 권장하지 않음 |

예: 일반 푸시업 `8·8·7회`에서 점차 `12·12·12회`로 발전한다. 상한 성공 조건을 충족하면 부하를 조절할 수 있는 변형을 다시 평가한다. `12·12·12회`가 쉬워졌다는 이유로 무조건 좁은 푸시업을 주지는 않는다. 좁은 손 간격은 자극과 관절 요구가 달라지는 별도 변형이다.

초기 변형의 예는 벽 → 사용 가능한 높은 지지대 → 낮은 지지대/무릎형 → 일반형이지만, 고정된 순서로 강제하지 않는다. 실제 목표 반복과 자세 유지 능력으로 선택한다. 지지대 높이가 달라지면 별도 부하 조건으로 기록한다.

브리지 → 한발 브리지는 같은 고관절 폄 목적에서 평가한다. 클램셸·옆으로 다리 들기와의 승급 연결은 제거한다. 스쿼트 → 스플릿도 부하뿐 아니라 균형 요구가 달라지므로 별도 적응 확인이 필요하다.

플랭크는 좋은 자세로 시간 상한을 2회 연속 달성하면 적합한 변형을 평가한다. 무한히 유지 시간만 늘리지 않는다. 한 번에 반복 수·세트 수·난도를 모두 높이지 않는다. 이상이 없는 2회 연속 성공 기준은 프로젝트 휴리스틱이다.

## 9. 8주 도입 예시

| 기간 | 근력운동 운영 | 확인할 내용 |
|---|---|---|
| 1~2주 | 주 2회부터, 각 슬롯 1~2세트, 여유 3~4회. 경험이 있고 회복이 좋으면 주 3회 가능 | 자세 학습, 운동 후 회복, 실제 가능한 변형 |
| 3~4주 | 회복·일정에 맞춰 주 2~3회. 선택 시간 템플릿으로 점진 접근, 여유 2~3회 | 실제 반복·세트 기록과 상한 도달 여부 |
| 5~8주 | 성공한 동작만 반복 또는 부하 증가. 필요할 때 세트 확대 | 같은 조건에서 수행량 증가, 지속 가능한 참여 |

주차가 바뀌었다고 자동 승급하지 않는다. 도입기에 더 오래 머물러도 된다. 피로가 누적되면 한 주 동안 세트를 줄이고 여유를 늘린다. 모든 사람에게 특정 주차의 의무 휴식주를 부과하지 않는다.

4주 간격으로 동일 변형·유사한 자세·비슷한 반복 여유에서 수행량을 비교한다. 최대 반복 실패 테스트나 체중 감소만으로 성공을 판정하지 않는다.

## 10. 유산소와 목표별 차이

기본 건강 목표는 중강도 유산소 주 150~300분 또는 상응하는 고강도 활동이다. 이는 장기적으로 접근할 목표이며 비활동자는 가능한 양에서 시작한다. 예를 들어 빠르게 걷기 30분×5일이면 주 150분이다. 걷기는 나눠 수행해도 되며 근력운동일에도 별도로 배치할 수 있다. [3]

중강도 걷기는 대체로 대화는 가능하지만 노래하기는 어려운 강도로 설명한다. 운동 경험이 적으면 편안한 걷기 10~15분부터 시작해 회복·일정에 따라 늘린다. 매주 정확히 몇 분씩 늘려야 한다는 고정 규칙은 두지 않는다. [7]

근력운동 화면을 켜 둔 전체 시간·휴식·가벼운 마무리를 자동으로 중강도 유산소 분량에 더하지 않는다.

| 사용자 목표 | 바꿀 요소 | 피할 처리 |
|---|---|---|
| 건강·습관 | 주 2~3회 지속, 20~30분형부터, 걷기 증가 | 완주 실패를 의지 부족으로 표시 |
| 근력 향상 | 적절한 더 어려운 변형·외부 부하, 충분한 휴식, 주요 동작 우선 | 반복 수·느린 속도만 끝없이 늘림 |
| 근육 증가 | 수행 질·회복을 유지하며 필요한 부위의 주간 세트와 부하 확대 | 모든 근육에 명목상 10세트를 일괄 강제 |
| 체중 관리 | 근력 유지용 저항운동과 걷기·전체 활동량, 식습관을 함께 검토 | 휴식만 20초로 줄여 감량 효과를 보장 |

체중 그래프는 같은 측정 조건에서의 추세 확인에 활용한다. 하루 변동을 근육 증가·지방 감소로 판정하지 않는다. 고령자용 모드는 WHO 권고에 따라 기능적 균형과 근력 중심의 복합 활동을 주 3일 이상 포함하도록 별도 설계한다. 현재 성인 기본형을 그대로 낙상 예방 프로그램이라 부르지 않는다. [3]

## 11. 앱 적용 명세

### 분류와 데이터

기존 `push/squat/hinge/pull/core`를 최소한 다음처럼 구분한다.

```text
kneeDominant       스쿼트·의자 스쿼트·스플릿·런지
hipExtension       브리지·한발 브리지
hipAbduction       클램셸·옆으로 다리 들기
horizontalPush     푸시업 변형
horizontalPull     새 밴드 로우
scapularAccessory  W·T 레이즈·스노우 엔젤
trunkControl       데드버그·버드독·플랭크·사이드 플랭크
```

세션에는 운동 ID뿐 아니라 `variant/loadConditions`, 목표 세트, 반복 하한·상한, 좌우 여부, 휴식, 예정 소요 시간을 둔다. 세트 기록에는 실제 완료 반복/시간, 좌우 수행, 반복 여유 또는 자세 종료, 통증·중단, 실제 휴식을 저장한다. 건너뛴 세트는 정상 수행으로 집계하지 않는다.

세션 당시 처방과 실제 수행을 스냅샷으로 보존한다. 규칙을 변경해도 과거 기록을 현재 추천으로 다시 해석하지 않는다. 새 데이터 형식은 버전을 올리고, 과거의 ‘보통/쉬움/힘듦’ 기록을 실제 반복이나 RIR로 지어내지 않는다.

### 추천·대체 순서

1. 가능한 요일·직전 운동일·회복 상태 확인.
2. 실제 장비와 지지 조건 확인. `stableChair`, `stableSurface`, 밴드 조건을 UI 입력과 연결.
3. 슬롯 목적과 현재 능력에 맞는 운동 선택.
4. 사용 불가·통증 반응에 따른 조정. 불편 부위만으로 어떤 대체 동작이 반드시 안전하다고 단정하지 않음.
5. **대체가 끝난 최종 운동 ID**로 중복과 슬롯 목적을 다시 검증.
6. 해당 목적을 충족할 수 없으면 빠진 슬롯을 표시. 무릎 운동 자리에 브리지를 두 번 넣어 전신 구성이 완성됐다고 처리하지 않음.
7. 시간 예산에 맞춰 세트 배분과 예상 시간 표시.
8. 실제 수행을 바탕으로 같은 운동·변형의 다음 목표 조절.

운동 시간이 짧아져도 코어를 자동 삭제하지 않는다. 사이드 플랭크는 좌우 한 쌍으로 생성한다. 45분 라운드 수가 최초 생성과 재설정 때 달라지는 문제를 없애고, 라운드 하나의 전역 값 대신 슬롯별 세트 수를 사용한다.

영상이 없는 새 동작은 다른 동작 영상으로 조용히 대체하지 않는다. 새 밴드 로우 도입 전까지는 기본형만 제공하고 당기기 부족을 표시할 수 있다. 영상 확보·가이드 검수 후 확장형을 활성화한다.

### 구현 순서와 완료 기준

1. 분류·대체 후 중복·실제 하향 조절·세트 수 불일치부터 수정.
2. 슬롯별 세트·반복 범위·초기 난도 선택·실제 수행 기록 도입.
3. A/B/C와 주간 회복 일정, 시간 예산 적용.
4. 걷기 계획과 주간 활동량을 근력운동에서 분리.
5. 장비 입력·밴드 로우 자료를 확보하고 확장형 추가.

추천 검사에는 무장비 입문자, 주 2회·20분, 중급자·30분, 주 5일, 하한 반복 미달, 2회 상한 성공, 회복 미흡, 좌우 코어, 불편 부위 대체 후 중복, 필수 슬롯 부재, 영상 없는 밴드 로우, 구버전 기록 이전을 포함한다. 부하·볼륨을 올리기 전에 사용자가 실제 수행·회복을 기록할 수 있어야 한다.

출시 후 평가는 완료율뿐 아니라 중단·통증 보고, 같은 조건에서의 수행 변화, 난도 하향이 필요한 빈도, 주간 참여를 함께 확인한다. 사용자 규모와 기간을 정해 전후 비교하되 대조군 없는 개선 수치를 곧바로 임상적 인과 효과로 표현하지 않는다.
