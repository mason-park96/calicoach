# 칼리코치 v1.3 — 개인 맞춤형 운동 코스 설계 및 근거

기준일: 2026-10-27 / 대상: 장비 없이 운동하는 성인, 개인 PWA

## 1. 설계 목표

- 최초 프로필 설정 이후 진입 즉시 오늘의 A/B/C 코스를 확인한다.
- 개인별 운동 경험, 정자세 푸시업 수행 횟수, 1회 운동 시간, 주당 운동 횟수, 우선 목표, 불편 부위에 따라 동작과 반복 수를 정한다.
- 실제 운동 중 동작별 수행 피드백을 받고 점진적 과부하를 적용한다.
- 한 번 진행한 운동의 스냅샷은 중간에 프로필이 바뀌어도 이어할 수 있도록 `active.steps`에 보존한다.
- 서버 없이 `localStorage['calicoach.pwa.v3.device']`를 사용하고 기존 v1.2 데이터를 그대로 읽는다.

## 2. 운동과학 근거

2026년 ACSM 저항운동 권고(Position Stand): https://pubmed.ncbi.nlm.nih.gov/41843416/
- 점진적인 저항운동과 일정 수준 이상의 노력 투입이 핵심이다.
- 주 2회 이상의 근력운동은 근력 향상에 유리하며, 근육량 향상에는 주당 근육군별 충분한 운동량이 중요하다.
- 모든 세트를 근육 실패 지점까지 수행할 필요는 없다. 남은 반복 여력(RIR) 2~3회는 실제 운동 강도의 실용적인 근사 지표다.
- 맨몸운동과 집에서 하는 근력운동도 효과적인 선택지다.
- 이 연구는 개인 맞춤 자동 추천 알고리즘 자체를 검증한 논문이 아니다. **아래 매칭 규칙은 근거 기반 원칙을 반영한 개발용 휴리스틱**이다.

2026년 ACSM 공식 안내: https://acsm.org/resistance-training-guidelines-update-2026/
ACE 동작 안내 라이브러리: https://www.acefitness.org/resources/everyone/exercise-library/
NHS 동작 안내 영상: https://www.nhs.uk/live-well/exercise/strength-and-flex-exercise-plan-how-to-videos/

## 3. 프로필 필드 및 적용

| 프로필 | 룰 |
|---|---|
| 운동경험(입문/보통/숙련) | 동작 난이도 기초 등급 |
| 정자세 푸시업 최대 횟수 | 푸시업 계열 단계 계산(미측정 시 경험 등급 사용) |
| 주당 운동 2/3/4/5회 | 2회인 경우 A/B 교대, 그 이상 A/B/C 교대(사용자가 원하는 날짜를 강제하지 않음) |
| 운동 20/30/45분 | 종목 수 4/5/5 및 라운드 2/3/3 기본값 |
| 우선 목표 | 근력 목표면 A 첫 운동의 푸시업 난도를 상대적으로 상승, 휴식 설정 사용 |
| 불편 부위(9항목 복수 선택) | 조건에 따라 특정 종목을 더 편안한 변형으로 대체 |
| 성별 | 표시 정보로만 사용. 성별 자체로 운동 난도를 차등하지 않음 |
| 현재/목표 체중 | 기록 및 체중 진행률. BMI만으로 강도를 자동 결정하지 않음 |

## 4. 불편 부위 세분화

목·경추, 어깨, 팔꿈치, 손목·손, 허리·척추, 골반·고관절, 무릎, 발목, 발바닥·발뒤꿈치.

체크한 부위가 **의학적 금기**를 뜻하지 않는다. 개인이 운동 중 주의하길 원하는 부위를 지정하는 것이다. 운동 자체는 일반적인 신체활동 조언일 뿐 진단·치료·재활 처방이 아니다. 불편이 악화되거나 통증·저림이 심해지면 해당 운동을 멈추고 전문가 상담을 권장한다.

예시 대체: 손목·팔꿈치→ 바닥 푸시업을 벽 푸시업으로 하향; 발바닥→ 리버스 런지 대신 제자리 스플릿 스쿼트; 발목→ 런지 대신 스쿼트; 무릎→ 하체 부하 종목 대신 브리지 계열; 허리→ 어려운 한발 브리지 대신 양발 브리지. 특정 동작이 불편하지 않으면 사용자가 프로필을 수정하거나 목표 횟수를 조절할 수 있다.

## 5. 동작 뱅크

- **푸시:** 벽 푸시업, 높은 지지대 푸시업(지지대 별도 필요), 무릎 푸시업, 일반 푸시업, 템포 푸시업, 좁은 푸시업.
- **하체:** 의자 스쿼트(의자 별도 필요), 스쿼트, 천천히 스쿼트, 스플릿 스쿼트, 리버스 런지.
- **엉덩이:** 글루트 브리지, 한발 글루트 브리지, 클램셸, 옆으로 누워 다리 들기.
- **등 상부 보조:** W 레이즈, T 레이즈, 리버스 스노우 엔젤.
- **코어:** 데드버그, 버드독, 플랭크, 양쪽 사이드 플랭크.
- **워밍업·쿨다운:** 기존 6종 유지.

장비 없이 **등 당기기 운동(수평/수직 로우)과 넓은등근 강화는 충분히 구현할 수 없다.** W/T 레이즈는 당기기 운동의 대체가 아니라 어깨 주변 보조운동이다. 앞으로 저항밴드, 철봉을 추가하면 균형 있게 재구성할 필요가 있다.

## 6. A/B/C 코스 구성

- A: 푸시→스쿼트→등 상부→엉덩이→코어.
- B: 하체 변형→푸시 변형→등 상부→엉덩이→코어.
- C: 푸시→엉덩이→스쿼트→등 상부→코어.
- 동일 동작 중복을 피하는 보정 로직과 보유 장비/불편 부위 조정 로직을 거친다.
- 20분은 주동작 4개, 2라운드, 30분은 주동작 5개, 3라운드, 45분은 5개, 3라운드+보강이다. **제시한 시간은 목표이고 실제 시간은 사용자의 속도와 휴식에 따라 차이**가 날 수 있다.

## 7. 사용자 피드백 기반 점진적 과부하

운동 중 매 본운동 단계마다 세 개 선택:
- `했어요`: 적당한 강도(기본 선택). 계획 조정 없음.
- `너무 쉬웠어요`: 해당 움직임 범주의 다음 세션 목표치 상승 후보.
- `너무 어려웠어요`: 해당 범주의 다음 세션 목표치 감소 후보.

운동 종료 시 해당 세션의 피드백만 한 번 집계한다.
- 쉬움 평가가 2회 이상이고 보통/어려움 이상으로 많으면, 해당 움직임 범주의 `bonus`(추가 목표 반복 또는 초)를 +1로 설정, 연속 '쉬운 세션' 횟수 증가.
- 어려움 평가가 1회 이상이면 `bonus`를 -2(0 미만 불가) 및 연속 쉬움 횟수 초기화.
- 연속 쉬운 세션이 3회 이상이고 추가 횟수가 +4 이상이면 난도 단계 `tier` +1(상한 +2), 반복 추가치 초기화.
- 어느 조건에도 들지 않으면 연속 쉬움 횟수 초기화.

중요: 이것은 **개인 기록 기반의 투명한 경험적 조정 규칙**이며 알고리즘의 의학적 안전성이나 실제 근력 향상 효과는 별도 검증된 것이 아니다. 사용자 수가 적기 때문에 향후 단순하고 감사 가능한 로직을 우선한다.

## 8. 애니메이션 / 미디어 정책

`media/*.gif`: 운동별 매핑된 애니메이션 29개. 본 프로젝트용으로 직접 생성한 움직임 **개념도**이며, 실제 사람의 자세를 정확히 촬영한 동영상은 아니다. 운동을 처음 배우는 사용자는 애니메이션과 함께 표시되는 단계별 설명을 반드시 확인해야 한다. 자세 시범을 더 명확히 제공하기 위해 추후 실제 출연자 영상 제작 또는 검증되고 이용 권한이 확인된 라이브러리 도입이 필요하다.

허가가 불분명한 타사 GIF를 GitHub 공개 저장소에 재배포하지 않는다. 모든 GIF는 서비스 워커에 사전 캐시하므로 최초 정상 설치 이후 오프라인에서도 시연 가능하다.

## 9. 호환성·개선 과제

- v1.2 로컬 키 `calicoach.pwa.v3.device` 유지; 구버전 `workouts`, `weights`, `profile`, `settings`, `active.steps` 필드 유지.
- 새 필드: `programIndex`, `progress`, `profile.adjustAreas`, 운동 중 `active.feedback`.
- JSON 백업은 버전 4로 올리고 1~4 버전을 가져올 수 있다.
- 남은 과제: 실제 동작 지도 영상 확보, 부위별 강도/증상 등급, 운동 완료 후 RIR 입력 정확도, 계획 시간 자동 보정, 장비 추가 지원, 회차별 반복 로그, 통증 악화 자동 중단 안내 UX.
