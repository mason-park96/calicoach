# 간편 수준 설정과 날짜 입력 보완

2026-10-28. 사용자의 우선 가치인 **간편함**을 기준으로 실제 소스에 반영했다.

## 운동 수준

설정에서 초급·중급·고급 중 하나를 누르면 저장하고 다음 새 운동에 적용한다. 진행 중인 세션은 그대로 유지한다. 수준 변경 전 세션의 피드백으로 새 설정을 덮어쓰지 않는다.

| 선택 | 기본 동작 방향 | 30분의 기본 세트 배분¹ |
|---|---|---|
| 초급 | 벽 푸시업 또는 확인한 높은 지지대, 스쿼트·양발 브리지·기초 코어 | 2 / 2 / 2 / 2 / 1 |
| 중급 | 무릎 푸시업, 스쿼트·양발 브리지·데드버그/버드독 | 3 / 3 / 2 / 2 / 2 |
| 고급 | 일반 푸시업, 템포/조건에 맞는 스플릿 스쿼트·한발 브리지·플랭크 | 3 / 3 / 3 / 3 / 2 |

¹ 하체 / 밀기 / 고관절 폄 / 견갑 보조 / 코어. 좌우 동작·휴식·시간 예산에 따라 세트 수를 줄일 수 있다. 불편 부위와 확인한 장비·수행 조건을 우선한다. 고급의 느린 동작이 언제나 더 효과적이라는 의미는 아니다.

반복·시간 목표도 수준에 따라 달라진다. 과거 푸시업 최대 기록이나 완료 횟수로 선택 수준을 자동 변경하지 않는다. 피드백은 선택한 수준 안에서 반복을 조절하고 어려울 때 낮추는 데 사용한다. 상위 변형으로 자동 승급하지 않는다. 같은 수준을 다시 누르면 기본 강도를 재적용하며 통증으로 제외한 범주는 유지한다.

## 간편한 진행

- 보통은 운동을 시작하고 각 동작에서 `완료`만 누른다.
- 실제 횟수 수정은 접힌 선택 항목으로 제공한다.
- 프로필의 환경·불편 부위, 설정의 세트·휴식은 필요한 경우에 펼친다.
- 최근 근력운동과 간격이 부족한 경우에만 회복 선택을 안내한다.
- 기존 운동·체중 기록과 백업 기능을 유지한다.

## 입력칸 레이아웃

- 생년월일과 날짜 입력은 독립된 행을 사용한다.
- 날짜·월 입력에 부모 폭을 넘지 않는 명시적 너비·최대 너비·최소 너비를 적용한다.
- WebKit 날짜 내부 표시의 최소 폭과 패딩을 조정한다.
- 370px 이하에서는 월 이동 버튼·월 입력을 한 행에, `이번 달`을 별도 행에 배치한다.
- 체중·걷기 입력에서도 날짜 필드가 다른 입력과 겹치지 않게 한다.

## 검증

후속 UI 문구 정리: 반복 안내·장식 문구를 제거하고 저장·회복·삭제 안내를 축약했다. 변화율 기준과 운동 안내는 펼쳐보기로 제공한다. 추천 엔진과 동작 가이드 원문은 변경하지 않았다.

- `node tests/smoke-test.js`: 수준 선택·저장·새로고침, 이전 세션 분리, 기존 달력·체중·백업·초기화 등.
- `node tests/training-engine-test.js`: 13,824개 조합, 수준별 동작, 자동 승급 방지, 하향·통증 처리 등.
- `node tests/guide-test.js`: 기존 29개 시연·가이드 연결.
- 로컬 브라우저 320px·390px에서 날짜·월 입력의 부모 경계와 페이지 가로 넘침 확인. 실제 iPhone Safari 기기 검증을 대신하지 않는다.

## 후속 사용성 개선

걷기 입력·목록·주간 목표를 제거했다. 기존 데이터는 백업 호환을 위해 보존한다. 운동 시연은 최소 250px 이상의 영역을 사용하며 제목·횟수 글씨를 줄였다. 확대 버튼으로 영상·GIF를 화면 전체에서 볼 수 있고, 확대 중에는 운동 타이머를 일시정지한다. 영상은 잘리지 않도록 비율을 유지한다.
