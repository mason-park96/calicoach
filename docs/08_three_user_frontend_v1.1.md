# 칼리코치 PWA v1.1 · 3인 프론트엔드 설계

## 1. 범위

백엔드·클라우드·데이터베이스 **사용하지 않음**. GitHub Pages 정적 사이트에서 모두 동작하며 개인별 프로필 및 운동 기록은 각 기기의 브라우저 저장소에 저장.

### 정해진 계정

| 계정 ID | 표시 이름 | 성별 |
|---|---|---|
| park | 박무승 | 남성 |
| lee | 이수희 | 여성 |
| kwon | 권승용 | 남성 |

사용자명은 표시 및 선택용이며 안전한 인증 수단이 아님. 실명은 Public GitHub 저장소에서 확인할 수 있음.

## 2. 화면 흐름

```text
로그인 화면
  ├─ 등록 이름 선택 / 입력
  └─ 자동 로그인 체크
       ↓
   프로필 존재?
       ├─ 아니요 → 신체정보 입력(최초 1회) → 홈
       └─ 예 → 홈 (진행 중 운동이 있으면 운동 화면)
                ↓
        A/B 루틴 · 기록 · 설정
                ├─ 신체정보 수정
                ├─ 로그아웃 / 사용자 변경
                ├─ JSON 백업·복원
                └─ 현재 사용자 운동·체중 기록 초기화
```

## 3. 저장소 모델

| Key | 내용 |
|---|---|
| `calicoach.pwa.v2.autoUser` | 자동 로그인을 선택한 사용자 ID |
| `calicoach.pwa.v2.tabUser` | 비자동 로그인 사용자 ID (sessionStorage) |
| `calicoach.pwa.v2.user.park` | 박무승 프로필·운동 기록·설정 |
| `calicoach.pwa.v2.user.lee` | 이수희 프로필·운동 기록·설정 |
| `calicoach.pwa.v2.user.kwon` | 권승용 프로필·운동 기록·설정 |
| `calicoach.pwa.v1` | 기존 v1.0 원본 데이터. 자동으로 삭제/이동하지 않음 |

모든 사용자 저장 데이터는 각 장치와 브라우저 컨텍스트에서만 이용할 수 있음. 사용자 선택에 따른 분리는 편의 기능이며 보안 격리가 아님.

## 4. 운동 개인화 로직

- 입력값: 생년월일·키·현재 체중·목표 체중·경험 수준·푸시업 최대 횟수(선택)·주당 운동 횟수·운동 시간·운동 우선 목표·운동 제약.
- 경험에 따라 루틴 A/B 동작 선택: 입문(무릎 푸시업) / 보통(일반 푸시업 및 런지) / 숙련(템포 푸시업 및 일부 난도 상향).
- 20분=기본 2라운드, 30분=3라운드, 45분=4라운드. 실제 운동 시간은 수행 속도에 따라 달라지며 설정 화면에서 라운드 수를 변경 가능.
- 감량 중심 초기 휴식=20초, 균형=25초, 근력 중심=40초. 스스로 설정값 변경 가능.
- 정자세 푸시업 최대 횟수를 입력하면 푸시업 초깃값을 보수적으로 조정.
- 몸의 제약 사항은 조정 참고값이며 의료 판정에 사용하지 않음.
- 성별만으로 운동 강도 자동 판정하지 않음.
- 체중 및 체중 목표는 현재 상태/기록용으로 표시하며 의료적 처방이나 칼로리 계산에 사용하지 않음.
- 첫 코스 이후 A/B 자동 교대, 완료 상태 독립적으로 저장.

## 5. 기존 버전 호환

- `v1` LocalStorage를 읽지만 자동 변경하지 않음.
- 같은 기기에 기존 v1 데이터가 있는 박무승 계정에서 사용자 선택 후 프로필 설정 시, 체중·목표 체중을 초기 입력 도움으로 제공 가능.
- 설정에서 명시적으로 `v1.0 기록 가져오기` 실행하면 박무승 계정에 복사. 새 계정의 기존 운동 기록을 덮어쓰므로 확인창과 백업 안내 제공.
- 원본 `calicoach.pwa.v1`은 남겨둠.
- PWA service worker 캐시명 `calicoach-shell-v1.1.0` 사용.

## 6. 인수 기준

1. 3명 외 이름으로 로그인할 수 없음.
2. 자동 로그인 ON/OFF에 따라 해당 기기에서 세션 동작이 분리됨.
3. 신규 사용자 프로필은 다른 사용자와 섞이지 않음.
4. 프로필 저장 후 앱 재진입 시 값 복원.
5. 사용자별 A/B 루틴과 주당 목표/세트·횟수·휴식이 적용됨.
6. 사용자별 운동 기록과 체중 기록이 분리됨.
7. 기존 v1.0 기록은 강제 이관하지 않음.
8. 백업 파일에 사용자 ID를 기록하고 다른 사용자 v2 백업의 복원 방지.
9. 백엔드/API가 없어도 전체 운동 진행 가능.
10. JavaScript 문법 검사 및 상태 전환·데이터 분리 로직 테스트 통과. Safari 실기기 동작은 배포 후 확인.
