# Calicoach v1.4 — 동작 학습 UI 설계 및 운영 가이드

## 변경

- 통증 관련 공통 알림은 `통증이 발생하면 동작을 중단하고 강도를 조정하세요.` 문구로 통일 (운동 중 공통 안내)
- 프로필 신규/수정은 `확인` submit에서만 저장; 이후 홈 진입 시 적용 완료 피드백. 저장 후 다음 세션에서 새 코스를 생성함. 진행 중 세션은 이전 단계/구성을 유지.
- 홈 미리보기/운동 중/휴식 중 모두 `동작 배우기` 진입
- 시작 자세 → 수행 동작 → 자세 확인 3단계 자체 제작 설명; 29종 수록
- GIF는 개념 움직임으로만 표기, 동작별 검증된 ACE 사진 자료 또는 NHS 영상 페이지로 외부 링크 (확인된 운동만 링크). 저작권 보호를 위해 외부 사진·영상을 앱에 복제하거나 호스팅하지 않음.
- 운동 또는 휴식 타이머가 진행 중 동작 학습을 열면 일시정지; 닫은 후 수동 재개.

## 아쉬운 점/추후 작업

1. 실제 인체 모델의 5~12초 반복 시연을 운동별로 촬영·제작 후 프로젝트 `media/demo/`에 추가 (최우선)
2. 촬영 시 정면/측면, 시작 자세/하강/상승 등 주요 프레임 표시, 흔한 오류를 음성 또는 자막으로 안내
3. 인물 초상권 및 영상 사용 라이선스 확보 후만 리포지터리에 포함
4. 실제 영상은 MP4(H.264) 또는 WebM 대안으로 제공, iPhone은 H.264 MP4 우선. 기본 `playsinline muted loop` / 재생속도 옵션 권장.
5. 오프라인 용량 증가를 고려하여 미디어는 점진적으로 캐시하고 앱 업데이트는 코드와 영상 캐시를 분리.
